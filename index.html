How to validate your generated code

  1. Generate your obfuscated snippet from the root URL above.
  2. Add the generated snippet to your target site template (for example, before </body>) so it runs on page load.
  3. Test copy behavior by selecting normal page text, copying, and pasting into a plain textarea or note app to confirm Source: current page URL is appended.

Option A: Deployed-domain validation

  1. Deploy your snippet to pages on the same root domain you used in the generator.
  2. Verify copied text includes Source links that match each page URL across multiple routes.

Option B: Local and dev-environment validation

  1. Use your normal local host (for example localhost, 127.0.0.1, or a LAN IP like 192.168.x.x) while developing.
  2. Paste the generated snippet into your local template or test page, refresh, then copy text to verify Source is appended in local runs too.
  3. Remove the snippet from temporary test pages once validation is complete and keep the production placement only where required.
